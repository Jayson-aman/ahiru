# 液化石油ガス設備士 —— いま、国が点検を求めている設備を扱える人

> note掲載用。タイトル案：
> - LPガス設備士という資格が、静かに重みを増している
> - 全国一斉点検の要請。それを実施できるのは誰か
> - 「配管は目視で分かる」と思っている人ほど読んでほしい

---

## 2026年8月5日に起きたこと

経済産業省が、全国のLPガス販売事業者に対して設備点検を要請しました。対象は商業施設や病院など、不特定多数が集まる大型施設です。

背景には、7月28日に熊本県嘉島町のイオンモール熊本で発生した爆発事故があります。7名が亡くなり、5名が負傷しました。経産省の公表では、令和8年熊本地震で建物内のLPガス配管が損傷し、漏れたガスが滞留して引火した可能性が高いとされています。

この記事は、事故を宣伝の材料にするために書くものではありません。ただ、ここから導かれる事実が一つあります。

**行政が点検を要請しても、点検を実施できるのは有資格者だけです。**

液化石油ガス設備士は、液化石油ガス法にもとづく国家資格です。硬質管の接続、気密試験、燃焼器との接続といった特定の作業は、この資格を持つ人でなければ行えないと法律で定められています。無資格者が代わりに行うことは認められていません。

対象施設が増え、点検の頻度が上がり、損傷が見つかれば改修工事が発生する。その全工程に有資格者が必要になります。

## この資格が扱う領域

液化石油ガス設備士の仕事は、ボンベから燃焼器までの一連の供給設備です。

容器（ボンベ）、調整器、供給管、配管、ガス栓、燃焼器。この経路のどこかに不具合があれば、ガスが漏れます。地震で配管が動けば、接続部に応力がかかります。目視で見える範囲だけを見ても、壁の中や床下の損傷は分かりません。

だからこの資格では、**漏れを「探す技術」**が問われます。気密試験の手順、圧力の保持時間、判定基準。どれも、なぜその手順なのかを理解していないと、現場で応用が効きません。

都市ガスが通っていない地域では、LPガスが生活インフラそのものです。日本の世帯の相当数がLPガスを使っています。この設備を維持できる人がいなくなると困る人が実際にいる、という種類の仕事です。

## 試験でつまずくポイント

**燃焼計算**。理論空気量、実際空気量、空気過剰率。プロパンとブタンで数値が変わります。化学反応式から必要酸素量を出して、空気中の酸素濃度で割り戻す。この流れが頭に入っていないと、数字を眺めても解けません。

**供給方式の違い**。戸別供給、集団供給、導管供給。それぞれで調整器の構成が変わり、必要な保安措置も変わります。文章だけで読むと、どれも似た説明に見えてしまう分野です。

**気密試験と耐圧試験の区別**。試験圧力、保持時間、判定基準が別物です。混同したまま覚えると、選択肢で必ず引っかかります。

**法令の作業範囲**。どの作業が有資格者でなければできないのか。ここは条文の読み取りが問われるので、丸暗記では対応しきれません。

これらはすべて、**構造を図で押さえてしまえば一気に楽になる**分野です。逆に言えば、図なしで文章だけを読んでいる限り、いつまでも曖昧なままになります。

## QualiZの液化石油ガス設備士

私たちのアプリQualiZ（クオリズ）は、その「図で押さえる」を徹底しています。

**要点テキスト312セクション・約13.2万字**を、基礎64節／燃焼64節／供給設備64節／消費設備64節／法令56節に分けて収録。各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で並んでいます。予備知識ゼロから読み始められる構成です。

**問題は600問**。全問に、正解の理由だけでなく「他の選択肢がなぜ誤りなのか」の解説をつけています。

そして**全600問に図解**があります。供給設備なら、ボンベから燃焼器までの経路を1枚の図にする。燃焼計算なら、空気量の内訳を図で分解する。ベクター形式の図解が311問に入っているので、iPadで拡大しても線が潰れません。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。高圧ガス製造保安責任者の丙種化学（液石）と併せて狙うなら、全22資格が使い放題になる月額2,800円／年額28,000円のプランの方が安く済みます。

各科目10問まで無料で解けます。
