# 建設コスト管理士 —— 積算ができる人は、なぜ重宝されるのか

> note掲載用。タイトル案：
> - 資材が上がり続ける時代に、積算の精度が効いてくる
> - 建設コスト管理士は、利益を作る側の資格
> - 数量拾いは、慣れではなく技術である

---

## 利益を左右する仕事

建設業では、受注時の見積もりが利益をほぼ決めます。

資材価格が上がり、労務費も上昇している状況では、この重みがさらに増します。積算を誤れば、工事を完成させても赤字になる。逆に高く見積もれば、そもそも受注できない。

**建設コスト管理士**は、この積算とコスト管理の専門資格です。公益社団法人 全国建設室内工事業協会などが関わる建築コスト管理士とは別に、建設分野のコスト管理を体系的に扱う資格として位置づけられています。

この仕事の価値は、**代替が効きにくい**点にあります。図面から数量を正確に拾い、単価を当て、諸経費を積み、契約条件を読み込む。経験と体系的知識の両方が要ります。

## 扱う範囲が広い

この資格の特徴は、単なる数量計算にとどまらないことです。

**積算**。図面から数量を拾い、単価を掛け、工事費を算出する。数量拾いには標準的な計測ルールがあり、それを知らないと人によって数字が変わります。

**契約**。請負契約の構造、約款、変更・追加の扱い、瑕疵担保、支払い条件。**契約条件を読めないと、追加工事の費用を回収できません**。実務ではここでの損失が大きい。

**建設経済**。資材価格の動向、労務単価、物価スライド、インフレ条項。マクロな価格変動を工事費にどう反映するか。

**概論**。建設業の仕組み、発注方式、入札制度、コストマネジメントの考え方。

範囲が広く、しかも法律・会計・工学が混ざります。専門が一つに定まらないぶん、独学だと全体像を掴みにくい資格です。

## QualiZの建設コスト管理士

**要点テキスト485セクション・約80.2万字**——これは収録22資格の中で**最大の分量**です。

概論120節／積算120節／契約125節／建設経済120節に配分しています。範囲の広さに対応するには分量が要ると判断しました。特に契約分野に125節を割いているのは、実務で損失が出やすく、かつ独学で押さえにくい領域だからです。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。会計や契約のように馴染みの薄い分野も、前提から読み始められます。

**問題は1,220問**。全問に、選択肢ごとの正誤解説をつけています。契約や制度の分野は「どこが違うか」で問われるので、誤答理由の解説が特に効きます。

**全1,220問に図解**があります。積算は数量の拾い方を図面上で示し、契約は当事者間の権利義務を関係図で、建設経済は価格変動の反映を流れ図で。**契約関係のような抽象的な内容ほど、関係図があると整理されます**。

法改正・最新統計に対応しています。建設業法の金額要件や労務単価は改定が入るので、古い数値のままの教材は危険です。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。施工管理技士各種と併せて持つと、現場と原価の両方を見られる人材になります。その場合は全22資格が使い放題の月額2,800円／年額28,000円をおすすめします。

各科目10問まで無料です。
