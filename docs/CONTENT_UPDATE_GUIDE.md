# コンテンツ定期更新ガイド（統計・法改正）

このアプリの問題・テキストには「毎年更新が必要な数値」が含まれます。
公表スケジュールに合わせて、以下の時期に更新してください。
GitHub Actions（`.github/workflows/content-update-reminder.yml`）が各時期に
リマインダーIssueを自動作成します。Issueが立ったら、Claudeのセッションで
下の「依頼文テンプレ」を送るだけで、Web検証→修正→コミットまで実行されます。

## 依頼文テンプレ（Claudeにそのまま送る）

```
docs/CONTENT_UPDATE_GUIDE.md に従って、今月の定期更新を実行してください。
最新の公表値をWebで検証してから該当ファイルを修正し、コミット・プッシュしてください。
```

特定分野だけなら：
```
令和◯年地価公示が公表されたので、宅建の統計問題を最新にしてください。
```
