# 一級建設機械施工管理技士 —— 機械を動かす人ではなく、機械の配置を決める人

> note掲載用。タイトル案：
> - 建設機械施工管理技士は、なぜ知名度の割に強いのか
> - ICT施工の時代に、機械を仕切れる人が足りない
> - 重機の選定は、感覚ではなく計算でできる

---

## 知名度と実力が釣り合っていない資格

建設機械施工管理技士は、施工管理技士6種の中では知名度が低い方です。しかし持っている人の希少性という点では、むしろ有利に働きます。

この資格は、建設業法上の**監理技術者**および**専任技術者**の要件を満たします。土工事、造成、解体、舗装など、重機を使う工事を仕切る立場に必要な資格です。

そして近年、この分野の中身が変わってきています。ICT建機、マシンガイダンス、マシンコントロール、ドローン測量。i-Constructionの流れで、建設機械の運用は「操作の巧拙」から「計画と管理」へ比重が移っています。

つまり、**機械を上手に動かせる人**と、**どの機械を何台、どう配置すれば工期内に終わるかを設計できる人**が、別々に必要になったということです。後者を担うのがこの資格です。

## 試験の中身とつまずき

**建設機械の種類と特性**。ブルドーザ、バックホウ、ローダ、ダンプ、締固め機械。それぞれの作業能力、適用土質、走行方式。単なる暗記に見えますが、機械の構造を理解していないと選定問題で迷います。

**施工計算**。作業能力の算出、サイクルタイム、土量変化率。地山土量・ほぐし土量・締固め土量の換算は定番の落とし穴で、どの係数をどちらに掛けるかで符号を間違えます。

**原動機と油圧**。エンジンの構造、油圧回路。油圧は圧力と流量の関係を回路図で追えるかどうかが分かれ目です。

**土工と舗装**。切土・盛土、法面保護、路床・路盤・表層。層構成を断面図で押さえると一気に整理されます。

**施工管理法と法規**。労働安全衛生法の重機関連規定は出題が厚い分野です。機械ごとの資格要件、作業主任者の選任、安全基準。

## QualiZの一級建設機械施工管理技士

**要点テキスト300セクション・約65.8万字**を、土木一般75節／建設機械75節／施工管理75節／法規75節に配分しています。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成。機械の構造のように前提知識が要る分野でも、導入から順に読めます。

**問題は1,240問**と、収録資格の中でも上位の分量です。全問に、選択肢ごとの正誤解説をつけています。

**全1,240問に図解**を添えています。土量変化率は地山・ほぐし・締固めの関係を図で示し、油圧回路は回路図で、舗装は層構成の断面図で。特に土量換算のような「どちらに掛けるか」で迷う論点は、図で方向を押さえてしまうのが確実です。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。土木施工や建築施工と併せて狙うなら、全23資格が使い放題の月額2,800円／年額28,000円をおすすめします。

各科目10問まで無料です。
