# 二級建築士 —— 設計と工事監理を、自分の名前でできるようになる

> note掲載用。タイトル案：
> - 二級建築士は、独立を視野に入れられる資格
> - 学科で落ちる人は、法規で時間切れになっている
> - 製図は別物の試験。だから学科は早く終わらせる

---

## 名前で仕事ができる資格

二級建築士は、建築士法にもとづく国家資格です。一定の規模・用途の範囲内で、**設計と工事監理を独占的に行えます**。

木造2階建て住宅を含む、一般的な住宅の設計はこの資格でカバーできます。住宅設計を主戦場にするなら、二級建築士は十分に実用的な資格です。

そして、これは**自分の名義で仕事ができる**資格でもあります。設計事務所を開設する道が開けます。会社に属して図面を描くのと、自分の責任で設計するのとでは、キャリアの性質が変わります。

施工側の人が取るケースも多い資格です。図面が読めるだけでなく、なぜその設計になっているかを理解できると、現場での判断が変わります。二級建築士から一級建築士へ進むルートもあります。

## 学科と製図、性質がまったく違う

**学科**は4科目。計画・法規・構造・施工。それぞれに足切りがあり、総得点だけでは受かりません。

**製図**は、事前に課題が公表され、当日その条件に沿って図面を仕上げます。学科とはまったく別種の訓練が必要です。

重要なのは、**学科と製図を同じ土俵で考えないこと**です。製図には手を動かす時間が要ります。だから学科はできるだけ効率よく終わらせて、製図に時間を残すのが定石です。

## 学科でつまずく場所

**法規**。ここが最大の関門です。

建築基準法、建築士法、都市計画法、消防法、バリアフリー法。試験では法令集の持ち込みが認められていますが、**持ち込めることが逆に罠になります**。

条文を引くのに時間がかかりすぎて、時間切れになる。これが法規で落ちる典型パターンです。法令集を引く前提で勉強すると、条文の位置を覚えないまま本番を迎えます。

必要なのは、「この論点はどのあたりに書いてある」という地図を頭に入れておくこと。そして、**引かなくても答えられる論点を増やしておくこと**です。

**構造**。構造力学の計算と、構造設計の知識。曲げモーメント図、応力度、部材算定。図が描けるかどうかで決まります。

**計画**。建築史、各種建築物の計画、環境工学。範囲が広く、暗記量が多い。

**施工**。工事の手順と管理。実務経験がある人には取りやすく、ない人には苦しい科目です。

## QualiZの二級建築士

**要点テキスト300セクション・約68.9万字**を、計画75節／法規75節／構造75節／施工75節に均等配分しています。

4科目に足切りがある試験なので、**どの科目も薄くしない**ことを設計方針にしています。得意科目で稼いで苦手科目を捨てる、という戦略が使えない試験だからです。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成されています。

**問題は600問**。全問に、選択肢ごとの正誤解説をつけています。法規のように「どこが違うか」が問われる科目では、誤答の理由まで押さえることが直接得点につながります。

**全600問に図解**があります。構造力学は応力図で、法規は斜線制限や採光の計算を図で、施工は工程の流れ図で、計画は平面図や断面図で。特に**高さ制限や日影規制のような空間的な規定は、図がないと理解できません**。

さらに、**製図対策のセクションを28節**収録しています。作図そのものは手を動かす訓練が必要ですが、課題の読み取り方、エスキスの手順、減点されやすいポイントといった前提知識はここで押さえられます。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。建築設備士や一級建築施工管理技士も収録しているので、建築系を横断するなら全23資格が使い放題の月額2,800円／年額28,000円が向いています。

各科目10問まで無料です。
