# 消防設備士（甲種）—— 工事・整備を独占できる、数少ない業務独占資格

> note掲載用。タイトル案：
> - 消防設備士は「点検が法律で義務」という需要構造を持つ
> - 甲種を取ると、工事まで請けられるようになる
> - スプリンクラーの作動原理を、図なしで説明されても困る

---

## 需要が法律で作られている

消防法は、建物の関係者に対して消防用設備等の**定期点検と報告**を義務づけています。点検を行えるのは消防設備士または消防設備点検資格者です。

これは景気とは無関係に発生する仕事です。建物が存在する限り、点検の周期は巡ってきます。しかも点検で不具合が見つかれば、整備・工事が必要になります。

さらに甲種消防設備士は、**工事**まで行えます。乙種は整備と点検のみです。この差が実務での役割と待遇を分けます。

業務独占資格——つまり無資格者が代わりにできない仕事——は、需要が資格保有者に集中します。消防設備士はその典型です。

## 類別という仕組み

消防設備士は扱う設備によって類が分かれています。

- **第1類**：屋内消火栓、スプリンクラー、水噴霧
- **第2類**：泡消火設備
- **第3類**：不活性ガス、ハロゲン化物、粉末消火設備
- **第4類**：自動火災報知設備、ガス漏れ火災警報設備
- **第5類**：金属製避難はしご、救助袋、緩降機
- **第6類**（乙種のみ）：消火器
- **第7類**（乙種のみ）：漏電火災警報器

実務でもっとも需要が多いのは**第4類**（自動火災報知設備）と**第1類**（スプリンクラー等）です。まず4類甲種から入る人が多く、そこから類を増やしていくのが定石です。

一つの類に受かると、次の類では共通部分（消防関係法令の共通部分、基礎的知識）が免除されます。**複数類を狙うなら、この免除制度を前提に計画を立てるべきです。**

## 試験でつまずく場所

**構造・機能**。ここが本体です。スプリンクラーヘッドの作動温度と感熱体、流水検知装置の動作、感知器の種類ごとの検出原理。**機器の内部で何が起きているかを図で理解しないと、記述式の実技で書けません。**

**基礎的知識（機械・電気）**。甲種では力学と電気の基礎が問われます。理系出身でない人が最初に止まる箇所です。

**消防関係法令**。共通部分と類別部分に分かれます。設置基準は建物の用途・規模・階数の組み合わせで決まるので、表を丸暗記しようとすると必ず破綻します。

**実技（鑑別・製図）**。甲種には製図があります。系統図を描く、機器を特定する。図が読めて描けることが直接問われる部分です。

この資格は、他のどの試験にも増して**図解が学習の中心**になります。感知器の内部構造、配線の系統、消火設備の配管経路。これらを言葉だけで覚えるのは、ほぼ不可能です。

## QualiZの消防設備士

**要点テキスト340セクション・約42.3万字**を、法令共通60節／法令類別60節／基礎的知識（機械）30節／基礎的知識（電気）30節／構造・機能（機械）50節／構造・機能（電気）50節／規格30節／実技30節に配分しています。

類別部分と共通部分を分けて収録しているので、免除制度を使う人も、必要な部分だけを重点的に学習できます。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。基礎的知識のように理系素養が前提になる分野も、導入から積み上げます。

**問題は1,200問**。全問に、選択肢ごとの正誤解説をつけています。

**全1,200問に図解**を添えています。感知器は内部構造の断面図で、スプリンクラーは配管系統と作動の流れで、避難器具は設置状態の図で。実技の製図対策としても、図を見慣れておくことが効きます。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。危険物取扱者乙4や電気工事士と併せて取る人が多い資格です。その場合は全23資格が使い放題の月額2,800円／年額28,000円をおすすめします。

各科目10問まで無料です。
