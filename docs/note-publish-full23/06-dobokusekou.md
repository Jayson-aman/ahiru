# 1級土木施工管理技士 —— インフラの更新は、これから本番を迎える

> note掲載用。タイトル案：
> - 高度成長期に造った橋とトンネルが、いま一斉に寿命を迎えている
> - 1級土木施工管理技士は「災害の後」に必要になる資格でもある
> - 土質と構造は、図で理解すると別物になる

## 仕事の総量が減らない分野

日本のインフラの多くは高度成長期に整備されました。橋梁、トンネル、上下水道、河川構造物。これらが一斉に更新時期を迎えています。

新設よりも維持・更新の比重が上がるというのは、**土木の仕事が減るのではなく質が変わる**ということです。既存構造物を使いながら補修する工事は、新設より制約が多く、施工計画の難度が高い。段取りを組める人の価値が上がります。

加えて、災害復旧があります。2026年の熊本地震のような地震、豪雨による河川氾濫、土砂災害。復旧工事は待ったなしで発生し、そのたびに現場を仕切れる技術者が必要になります。

1級土木施工管理技士は、建設業法上の**監理技術者**および**専任技術者**になれる資格です。公共工事の入札における経営事項審査でも評価対象になるため、会社にとっては受注力そのものに直結します。

## つまずきやすい論点

**土質力学**。土の三相構造、間隙比、含水比、圧密。土は液体でも固体でもない中間的な挙動をするので、直感が効きません。図で状態を把握しないと、公式が何を計算しているのか分からないまま進むことになります。

**構造力学**。曲げモーメント図、せん断力図、たわみ。図が描ければ解けます。描けなければ解けません。

**コンクリート工**。配合設計、水セメント比、スランプ、養生。数値の意味と相互の関係を押さえないと、条件が変わったときに対応できません。

**工程管理**。ネットワーク工程表、クリティカルパス、山積み・山崩し。これも図の分野です。

**専門土木の広さ**。河川、道路、橋梁、トンネル、海岸、港湾、鉄道、上下水道。すべてを深くやる時間はないので、出題の重みづけを踏まえた学習配分が要ります。ここを設計せずに参考書を頭から読むと、まず終わりません。

## QualiZの1級土木施工管理技士

**要点テキスト300セクション・約66.9万字**を、土木一般75節／専門土木75節／施工管理75節／法規75節に配分しています。専門土木の広い範囲も、セクション単位で区切ってあるので少しずつ潰せます。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。土質力学のように前提が必要な分野でも、導入から入れます。

**問題は710問**。全問に、選択肢ごとの正誤解説をつけています。

**全710問に図解**があります。土質は土の三相を模式図で、構造力学は応力図で、工程管理はネットワーク図で示します。土木は対象が大きく現物を見に行けないことが多い分野なので、図解の役割が大きいと考えています。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。建築・管工事・電気工事・建設機械・電気通信の施工管理も収録しているので、複数分野を狙うなら全23資格が使い放題の月額2,800円／年額28,000円が有利です。

各科目10問まで無料です。
