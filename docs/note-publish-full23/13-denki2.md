## 入口でありながら、独立もできる

第二種電気工事士は、一般用電気工作物——住宅や小規模店舗の電気工事を行える国家資格です。

この資格の特徴は、**入口であると同時に、それ単体で仕事になる**ことです。コンセントの増設、照明器具の交換、分電盤の工事、エアコンの電源工事。これらは無資格では行えません。実際に、この資格を足がかりに独立している人がいます。

そして受験資格に制限がありません。学歴も実務経験も不要で、誰でも受けられます。未経験から電気の世界に入るときの、事実上の標準ルートです。

需要側も動いています。EV充電設備の設置、太陽光パネルと蓄電池、住宅のリフォームに伴う電気工事、オール電化。工事の対象が増える方向にあります。

第一種電気工事士、電験三種、電気工事施工管理技士へと進む土台にもなります。

## 筆記より、技能試験で落ちる

試験は筆記（学科）と技能の2段階です。

**筆記**は、電気の基礎理論、配線設計、電気機器・材料、施工方法、検査、法令。マークシートで、合格ラインは6割です。過去問の傾向が安定しているので、対策しやすい部類に入ります。

問題は**技能試験**です。

事前に13問の候補問題が公表され、その中から1問が出題されます。制限時間40分で、支給された材料を使って実際に配線を完成させます。欠陥が一つでもあれば不合格です。

ここで落ちる人の理由はほぼ一つ、**複線図が描けない**ことです。

単線図で示された回路を、実際の配線——どの線がどこに繋がるか——に変換する作業。これができないと、材料を前にして手が止まります。時間内に終わりません。

複線図は、練習すれば必ず描けるようになります。ただし、**理屈を理解せずに13問の答えを丸暗記した人は、少しでも条件が変わると崩れます**。スイッチと負荷の対応、3路スイッチの結線、接地側と非接地側の区別。原理から理解しておく必要があります。

## 筆記でつまずく論点

**オームの法則の応用**。直列・並列の合成抵抗、分圧・分流。ここが曖昧だと、後続がすべて崩れます。

**交流回路と力率**。実効値、位相、力率。ベクトル図で捉えられるかどうかが分岐点です。

**配線設計**。許容電流、幹線の太さ、過電流遮断器の選定。表の読み方と条件の組み合わせで迷います。

**鑑別**。工具や材料の写真を見て名称と用途を答える問題。これは実物を見ていないと厳しい分野です。

**電気設備技術基準と法令**。接地工事の種類と接地抵抗値、施設できる場所の条件。数値の暗記が要ります。

## QualiZの第二種電気工事士

**要点テキスト300セクション・約64.6万字**を、電気理論75節／配線設計75節／電気機器・材料75節／法規75節に均等配分しています。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。電気を初めて学ぶ人が、オームの法則から順に積み上げられる構成です。

**問題は600問**。全問に、選択肢ごとの正誤解説をつけています。

**全600問に図解**があります。この資格は特に図解との相性が良い分野です。合成抵抗は回路図で、交流はベクトル図で、配線は複線図で、器具は外観と内部構造で。**複線図の考え方も図解で扱っている**ので、技能試験の準備としても使えます。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。電験三種や電気工事施工管理技士へ進むことを考えているなら、全23資格が使い放題の月額2,800円／年額28,000円のプランで、先の資格を覗きながら進めるのも一つの手です。

各科目10問まで無料です。
