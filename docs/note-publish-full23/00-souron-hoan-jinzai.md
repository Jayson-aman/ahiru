# 【総論】保安と施工の人材が、いま制度的に足りていない

> note掲載用。タイトル案：
> - 「点検してください」と国が言った。では、誰が点検するのか
> - 保安人材の不足は、もう「将来の課題」ではなくなった
> - 資格が“あると良いもの”から“ないと回らないもの”に変わる年

---

2026年8月5日、経済産業省が全国のLPガス販売事業者に対して一斉点検を要請しました。対象は、商業施設や病院など、不特定多数の人が集まる大型施設のガス設備です。

きっかけは、7月28日に熊本県嘉島町のイオンモール熊本で起きた爆発事故でした。7名の方が亡くなり、5名が負傷しています。経産省の公表によれば、令和8年熊本地震で建物内のLPガス配管が損傷し、漏れたガスが滞留して引火した可能性が高いとされています。

この文章は、その事故を商材の宣伝に使うために書くものではありません。ただ、この一連の出来事が、資格を取ろうか迷っている人にとって無視できない意味を持っているのは事実なので、そこだけを書きます。

## 「点検してください」の先にあるもの

行政が点検を要請したとき、その点検を実施できるのは有資格者だけです。

LPガス設備の調査・点検は、液化石油ガス法によって有資格者の業務と定められています。高圧ガスを扱う事業所には、高圧ガス保安法によって保安統括者・保安技術管理者などの選任義務があります。これは努力目標ではなく、法律上の義務です。

つまり、点検対象の施設が増えれば、それを回せる人が制度的に必要になります。人手が足りないからといって、無資格者に代わってもらうという逃げ道がありません。ここが、他の多くの仕事と決定的に違うところです。

そして今回の要請は、日常的な保安点検の枠を超えて、**地震で損傷した配管を見つけ出す**という難度の高い仕事を含んでいます。目視で分からない損傷をどう疑うか、どこを重点的に見るか。これは資格試験で問われる知識そのものです。

## 施工管理も、同じ構造にある

建設業では2024年4月から時間外労働の上限規制が適用されました。労働時間を減らしながら同じ工事量をこなすには、工程を組み立てられる人間が現場ごとに必要になります。

施工管理技士は、建設業法上の「主任技術者」「監理技術者」になれる資格です。一定規模以上の工事には、これらの技術者を専任で配置する義務があります。会社が工事を受注できるかどうかが、有資格者が何人いるかに直接かかっているということです。

建設業就業者の高齢化はよく指摘されるとおりで、資格を持ったまま引退していく層と、これから資格を取る層の数が釣り合っていません。この差は、資格保有者の交渉力として表れます。

## 「取るに越したことはない」の中身

資格を勧める文章はたいてい「取っておいて損はない」で終わります。それだと弱いので、もう少し具体的に書きます。

**第一に、配置義務のある資格は景気の影響を受けにくい**。工事量が減っても、工事をするなら技術者は要ります。保安の仕事は、設備が存在する限り発生します。需要が売上ではなく法令に紐づいているというのは、かなり強い性質です。

**第二に、資格手当は毎月出る**。多くの企業で施工管理技士やガス系資格には手当がつきます。仮に月1万円なら年12万円、10年で120万円。試験勉強にかけるコストとの比較で考えると、回収期間はそれほど長くありません。

**第三に、転職市場での通り方が変わる**。実務経験は面接で説明しないと伝わりませんが、資格は書類の段階で伝わります。書類で落とされなくなるというのは、思っているより大きな差です。

## それでも、勉強は続かない

ここまで書いておいて何ですが、資格取得の最大の障壁は「必要性が分からないこと」ではありません。**必要だと分かっていても続かないこと**です。

参考書を買った。最初の30ページは読んだ。そこから開いていない。この経験がある人は多いと思います。

理由ははっきりしていて、参考書は「読む」ようにできていて「分かる」ようにできていないからです。高圧ガスの断熱膨張、LPガスの燃焼計算、施工管理のネットワーク工程表。文章だけで理解するには無理がある内容を、文章だけで説明しようとしている。図が足りないんです。

## QualiZという選択肢

私たちが作ったQualiZ（クオリズ）は、この「図が足りない」を出発点にしたアプリです。

収録している23資格すべてで、**問題文と選択肢に加えて、なぜその選択肢が誤りなのかを一つずつ解説しています**。そして全30,350問に図解を添えています。仕組み・数値・流れを目で追えるようにしてあります。

要点テキストは1資格あたり300セクション以上、全体で6,577セクション・約1,255万字。市販の参考書を何冊分も超える分量ですが、各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」という同じ順番で並んでいるので、どこから読んでも迷いません。

学習データは端末内に保存され、アカウント登録は不要です。通勤中に3セクション読む、昼休みに10問解く、という使い方を想定しています。

各資格の詳しい紹介は、それぞれ個別の記事にまとめています。まずは無料で各科目10問まで解けるので、問題の質を見てから判断してください。
