# 一級建築施工管理技士 —— 会社が工事を取れるかどうかが、この資格にかかっている

> note掲載用。タイトル案：
> - 監理技術者がいないと、その工事は受注できない
> - 一級建築施工管理技士を「今」取るべき構造的な理由
> - 人手不足の現場で、いちばん値段がつく資格

---

## この資格が特殊な理由

一級建築施工管理技士は、建設業法上の**監理技術者**になれる資格です。

元請として一定金額以上の下請契約を結ぶ工事では、監理技術者を工事現場に専任で配置しなければなりません。これは義務なので、有資格者がいなければその工事は受注できません。

つまり、**この資格を持つ人の数が、会社が同時に抱えられる工事の数の上限を決めています**。営業がどれだけ頑張っても、技術者がいなければ案件を取れない。だから建設会社は有資格者を手放しません。資格手当が出るのも、引き抜きが起きるのも、この構造から来ています。

さらに、一級建築施工管理技士は建設業許可の**専任技術者**の要件も満たします。会社が許可を維持するために必要な人材でもあるということです。

## 人手不足は、まだ底を打っていない

建設業では2024年4月から時間外労働の上限規制が適用されました。

これが意味するのは、**同じ工事量を、より短い労働時間でこなす必要がある**ということです。残業で吸収していた分を、工程の組み方で吸収しなければならない。段取りを設計できる人間の価値が上がります。それが施工管理の仕事です。

加えて、建設業就業者の高齢化は長く指摘されてきたとおりです。資格を持ったまま引退していく層と、新たに取得する層の数が釣り合っていません。この不均衡は、有資格者の交渉力として現れます。

「人手不足だから今後発展する」というのは、しばしば根拠のない楽観として語られますが、施工管理に関しては**配置義務という法的な裏付けがある**点が違います。需要が景況感ではなく法令に紐づいているというのは、資格としてかなり強い性質です。

## 試験の構造と、落ちる理由

一次検定と二次検定に分かれています。

**一次検定**は、建築学・施工・施工管理法・法規の4分野。範囲が広く、建築という分野の全体を薄く広く問われます。構造力学、材料、各種工事の施工方法、工程管理、法規。得意分野だけで受かる試験ではありません。

**二次検定**は記述式です。ここで多くの人が止まります。経験記述、施工管理の応用、法規。**自分の現場経験を、採点者に伝わる文章として書けるか**が問われます。技術力があっても、書けなければ受かりません。

一次で落ちる人の典型は、範囲の広さに対して学習の順序を設計できていないケースです。参考書を1ページ目から読み、施工の章に入る前に力尽きる。よくある話です。

つまずきやすい具体的な論点を挙げると——

**ネットワーク工程表**。クリティカルパス、フロート、最早開始時刻。これは完全に図の話です。文章で説明されても頭に入りません。

**構造力学**。曲げモーメント図、せん断力図。図が描ければ解けて、描けなければ解けない。

**各種工事の施工手順**。鉄筋、型枠、コンクリート、鉄骨、仕上げ。順序と理由をセットで理解しないと、似た選択肢で迷います。

**建設業法の金額要件**。改正が入る分野なので、古い数値を覚えていると失点します。

## QualiZの一級建築施工管理技士

私たちのアプリQualiZ（クオリズ）は、この試験の「範囲が広くて順序が設計できない」問題に対して、構成で答えを出しています。

**要点テキスト300セクション・約70.2万字**を、建築学75節／施工75節／施工管理75節／法規75節に均等配分。各分野を同じ密度でカバーしているので、苦手分野だけ薄いということが起きません。各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成されています。

**問題は775問**。全問に、選択肢一つひとつの正誤理由を解説しています。

そして**全775問に図解**を添えています。ネットワーク工程表はクリティカルパスを色分けした図で、構造力学は応力図で、施工手順は工程の流れ図で示します。この分野は図解の有無で理解速度がはっきり変わります。

法改正・最新統計にも対応しています。建設業法の金額要件は改正が入る箇所なので、ここが古いままの教材は危険です。

本試験形式の模試はタイマー付きで、時間配分の練習ができます。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。土木・管工事・電気工事・建設機械・電気通信の施工管理も収録しているので、複数分野を狙うなら全21資格が使い放題の月額2,800円／年額28,000円のプランをおすすめします。

各科目10問まで無料です。
