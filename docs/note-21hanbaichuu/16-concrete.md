## 老朽化診断という、これから増える仕事

日本のコンクリート構造物の多くは、高度成長期以降に造られました。橋梁、トンネル、擁壁、建築物。これらが一斉に更新・補修の時期を迎えています。

ここで必要になるのが、**「まだ使えるのか、補修すべきか、造り替えるべきか」を判定できる人**です。

ひび割れを見て、それが乾燥収縮なのか、アルカリシリカ反応なのか、鉄筋腐食による膨張なのか、塩害なのか。原因が違えば対策が変わります。誤診すれば、補修しても再発します。

**コンクリート診断士**は、この判定を担う資格です。既存構造物の劣化診断と対策立案が守備範囲になります。

**コンクリート技士**は、コンクリートの製造・施工・品質管理を担う資格です。生コン工場、建設会社の品質管理部門で必要とされます。JIS認証工場では有資格者の配置が求められる場面があります。

順序としては、技士を取ってから診断士に進むのが一般的です。

## 学習でつまずく場所

**配合設計**。この分野は計算が絡み、しかも用語が紛らわしい。

水セメント比、単位水量、単位セメント量、細骨材率、空気量、スランプ。これらは互いに連動しています。水セメント比を下げれば強度は上がるが、施工性は落ちる。単位水量を減らせば乾燥収縮は減るが、打設が難しくなる。**トレードオフの構造を理解しないと、数値を覚えても使えません**。

**示方配合と現場配合の換算**。骨材の表面水率と吸水率を考慮して補正する計算です。どちらに足してどちらから引くかで、毎回迷う定番の落とし穴です。

**劣化機構**。中性化、塩害、凍害、アルカリシリカ反応、化学的侵食、疲労。それぞれ進行のメカニズムが違い、現れる症状も違います。**診断士では、症状から機構を逆算する力が問われます**。

**混和材料**。AE剤、減水剤、高性能AE減水剤、フライアッシュ、高炉スラグ。何のために入れるのか、どう効くのかを押さえる必要があります。

**試験方法と規格**。スランプ試験、空気量試験、圧縮強度試験、非破壊検査。手順と判定基準。

これらは**微視的な現象**を扱うので、目で見て確かめることができません。セメントの水和反応、塩化物イオンの浸透、鉄筋の腐食膨張。すべて、図で模式化してはじめて理解できる内容です。

## QualiZのコンクリート技士・診断士

**要点テキスト300セクション・約69.2万字**を、材料50節／配合50節／製造50節／施工50節／各種コンクリート50節／診断50節の6分野に均等配分しています。

技士の範囲（材料・配合・製造・施工・各種）と診断士の範囲（診断）を一つのアプリで扱えるので、**技士から診断士へ段階的に進む使い方**ができます。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成されています。

**問題は600問**。全問に、選択肢ごとの正誤解説をつけています。

**全600問に図解**があります。劣化機構は進行の過程を段階図で、配合は各材料の体積構成を図で、中性化や塩害は断面での浸透の様子を図で示します。**目に見えない微視的現象を扱う分野なので、図解が理解の入口になります**。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。土木施工管理技士や建築施工管理技士と親和性が高い資格なので、併せて狙うなら全21資格が使い放題の月額2,800円／年額28,000円が有利です。

各科目10問まで無料です。
