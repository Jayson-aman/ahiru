# 一級電気工事施工管理技士 —— 電化が進むほど足りなくなる人材

> note掲載用。タイトル案：
> - EV充電器、太陽光、蓄電池。全部この人がいないと据えられない
> - 一級電気工事施工管理技士が、いま構造的に不足している理由
> - 電気は目に見えない。だから図解で学ぶ意味がある

---

## 需要が増える方向にしか動いていない

電気工事の対象が、この10年で明確に増えています。

再生可能エネルギーの導入で太陽光発電設備と蓄電池。EV普及で充電インフラ。データセンターの新設と増設。工場の省人化に伴う制御盤の更新。そして既存建物の受変電設備の更新需要。

どれも「電気設備を新しく据える」「容量を増やす」仕事です。減る要素が見当たりません。

一級電気工事施工管理技士は、建設業法上の**監理技術者**および**専任技術者**になれます。電気工事業の許可を持つ会社にとって、この資格者の人数が受注できる工事の規模と数を決めます。

第二種・第一種電気工事士が「工事をする」資格だとすれば、施工管理技士は「工事を仕切る」資格です。両方持っていると、現場での立ち位置が変わります。

## この試験で止まる場所

**電気理論**。交流回路、力率、三相交流。ベクトル図で考えられるかどうかが分岐点です。「力率とは何か」を数式だけで暗記した人は、力率改善のコンデンサ容量を問われた瞬間に手が止まります。

**受変電設備**。変圧器の結線、保護継電器の協調、接地方式。単線結線図が読めないと、この分野はすべて暗記になります。逆に図が読めるようになると、一気に見通しが良くなります。

**照明計算**。光束法、照度、保守率。公式は単純ですが、どの係数が何を意味するのかを理解していないと、条件が変わると解けません。

**シーケンス制御**。自己保持回路、インターロック。これは完全に図の分野です。動作の順序を回路図の上で追えるかどうか。

**施工管理法と法規**。工程管理、品質管理、安全管理。電気事業法、電気工事士法、建設業法、労働安全衛生法。範囲が広いうえに、法改正が入ります。

共通しているのは、**電気は目に見えないので、図でしか捉えられない**という点です。配管や鉄筋なら現物を見れば分かりますが、電流の向きや位相のずれは図に描くしかありません。

## QualiZの一級電気工事施工管理技士

**要点テキスト300セクション・約68.3万字**を、電気理論75節／電気設備75節／施工管理75節／法規75節に均等配分しています。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成。電気理論のように積み上げが必要な分野でも、前提知識を飛ばさずに読み進められます。

**問題は1,240問**と、収録資格の中でも上位の分量です。全問に、選択肢ごとの正誤解説をつけています。

**全1,240問に図解**があります。三相交流はベクトル図で、受変電設備は単線結線図で、シーケンスは回路図で。電気という「見えない対象」を扱う以上、図解は装飾ではなく学習の本体だと考えています。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。第二種電気工事士や電験三種も収録しているので、電気系を段階的に取っていくなら全21資格が使い放題の月額2,800円／年額28,000円が向いています。

各科目10問まで無料です。
