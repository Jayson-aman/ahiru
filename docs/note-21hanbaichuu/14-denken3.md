# 電験三種 —— 難関だが、選任義務があるので需要が消えない

> note掲載用。タイトル案：
> - 電験三種は、なぜあれほど求人があるのか
> - 年2回化で、戦略が変わった
> - 科目合格制度を使い倒す前提で計画を立てる

---

## 選任義務という土台

第三種電気主任技術者、通称「電験三種」。

電気事業法は、事業用電気工作物を設置する者に対して**電気主任技術者の選任**を義務づけています。ビル、工場、商業施設、病院。高圧受電をしている施設には、必ず選任された主任技術者が要ります。

これは義務なので、有資格者がいなければ施設を運用できません。外部委託という手段もありますが、その委託先にも有資格者が必要です。需要の総量は変わりません。

そして電験三種の有資格者は、慢性的に不足しています。試験の難度が高く、合格者数が需要に追いついていない。加えて、既存の主任技術者の高齢化が進んでいます。

再生可能エネルギー設備の増加も需要を押し上げています。太陽光発電所にも主任技術者の選任が必要です。

## 難しい。それは事実として認める

電験三種は難関資格です。合格率は例年1割前後で推移してきました。

科目は4つ。**理論・電力・機械・法規**。

このうち**機械**が最大の壁とされています。変圧器、誘導機、同期機、直流機、パワーエレクトロニクス、自動制御、情報。範囲が広く、それぞれが独立して難しい。

**理論**は電磁気と回路。ここが弱いと機械も電力も理解できないので、実質的な土台です。

**電力**は発電・変電・送配電。計算と知識のバランスが取れた科目です。

**法規**は電気事業法と技術基準、そして施設管理の計算問題。暗記科目に見えて計算が出るので、油断すると落とします。

## 科目合格制度をどう使うか

電験三種には**科目合格制度**があります。合格した科目は一定期間有効で、次回以降は残りの科目だけ受ければよい。

そして近年、**試験が年2回実施**されるようになりました。これは戦略に大きく影響します。

以前は年1回だったので、4科目を一度に狙うか、数年計画で刻むかの二択でした。年2回になったことで、**半年ごとに2科目ずつ**といった刻み方が現実的になっています。

ただし、科目合格の有効期間には限りがあります。だらだら続けると、最初に取った科目の期限が切れて振り出しに戻ります。**計画を立てずに受け続けるのが、いちばん危険なパターン**です。

推奨される順序は、理論を最初に固めること。理論の理解が、電力と機械の土台になるからです。

## つまずく論点

**電磁気**。電界、磁界、電磁誘導。目に見えないものを扱うので、図なしでは無理があります。

**交流回路とベクトル**。複素数表示、インピーダンス、共振。ベクトル図で捉えられるかどうかで難度が変わります。

**変圧器と誘導機の等価回路**。等価回路が何を表しているのかを理解せずに公式を覚えると、応用問題で崩れます。

**自動制御**。伝達関数、ブロック線図、周波数応答。ブロック線図は図そのものが解法の道具です。

**施設管理の計算**。需要率、負荷率、不等率。定義を正確に押さえていないと、似た用語で取り違えます。

## QualiZの電験三種

**要点テキスト300セクション・約71.4万字**を、理論75節／電力75節／機械75節／法規75節に均等配分しています。

4科目を同じ密度でカバーしているので、科目合格制度を使って一科目ずつ攻める使い方に合います。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。電験は積み上げが要る試験なので、前提を飛ばさない構成にしています。

**問題は1,040問**。全問に、選択肢ごとの正誤解説をつけています。電験は「なぜその選択肢が誤りか」を理解しないと類題に対応できない試験なので、ここは特に厚くしています。

**全1,040問に図解**があります。電磁気は場のイメージを図で、交流はベクトル図で、等価回路は回路図で、自動制御はブロック線図で。電験は図解の価値がもっとも高い資格の一つです。

本試験形式の模試はタイマー付きで、科目別に演習できます。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。**数年かけて科目合格を積む試験なので、年額プランとの相性が良い**資格です。第二種電気工事士や電気工事施工管理技士も収録しているので、全21資格が使い放題の月額2,800円／年額28,000円も検討する価値があります。

各科目10問まで無料です。
