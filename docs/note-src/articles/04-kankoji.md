## 需要が消えない理由

管工事は、空調・換気・給排水・衛生・ガス配管を扱う分野です。

この領域が強いのは、**新築が減っても仕事がなくならない**ところにあります。建物は建った瞬間から劣化が始まり、設備の寿命は躯体より短い。空調機の更新、配管の更生、給湯設備の入れ替え。既存建物がある限り、改修需要が発生し続けます。

しかも改修は新築より難しい。稼働中の建物で、居住者やテナントの使用を止めずに設備を入れ替える。図面と現物が違うことも日常茶飯事です。段取りを組める人でなければ回りません。

1級管工事施工管理技士は、建設業法上の**監理技術者**および**専任技術者**になれる資格です。会社が管工事業の許可を維持し、大型案件を受注するために必要な人材ということになります。

2026年8月に経済産業省が大型施設のガス設備点検を要請したように、設備の保安に対する社会的な要求は上がる方向にあります。改修工事が増えれば、それを仕切る施工管理者が要ります。

## この試験の難所

**空調負荷計算**。室内の熱負荷を、外壁からの侵入熱、日射、人体、照明、換気に分解して積み上げる。どの要素がどれだけ効くかを理解していないと、数字の意味が分かりません。

**湿り空気線図**。管工事でもっとも脱落者が出る分野です。乾球温度、湿球温度、絶対湿度、相対湿度、エンタルピー。1枚の図の上で状態変化を追う内容なので、**図なしでは絶対に理解できません**。文章で説明された湿り空気線図ほど不毛なものはありません。

**ポンプの特性と配管抵抗**。揚程、実揚程、摩擦損失。ポンプ性能曲線と抵抗曲線の交点が運転点になる、という理解が図で入っているかどうかで難度が変わります。

**通気管の方式**。各個通気、ループ通気、伸頂通気。封水を守るための仕組みなので、なぜ必要かを配管図で押さえないと、方式の違いが暗記になります。

**施工管理法と法規**。工程・品質・安全・原価の管理と、建設業法・労働安全衛生法・建築基準法・水道法。範囲が広く、後回しにされがちで、そのまま本番を迎える人が多い分野です。

## QualiZの1級管工事施工管理技士

**要点テキスト300セクション・約58.3万字**を、原論60節／空調60節／衛生60節／施工60節／法規60節に配分しています。5分野を均等に押さえられる構成です。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。湿り空気線図のような分野こそ、この構成が効きます。

**問題は1,200問**。全問に、選択肢ごとの正誤解説をつけています。「なぜ他の3つが誤りなのか」まで分かると、類題への対応力が変わります。

**全1,200問に図解**があります。湿り空気線図は線図そのものを載せて状態変化を追えるようにし、通気方式は配管の立面図で示し、ポンプ特性は性能曲線と抵抗曲線を重ねた図で示します。この試験は図解の有無で学習効率がもっとも変わる分野の一つだと考えています。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。建築・電気・土木など他の施工管理分野も収録しているので、複数狙うなら全23資格が使い放題の月額2,800円／年額28,000円が有利です。

各科目10問まで無料で試せます。
