> - 実技試験は「作図」で決まる

## 災害が増えるほど、需要が変わる

気象予報士というと、テレビの気象キャスターを思い浮かべる人が多いと思います。しかし実際に人材が求められているのは、別の領域です。

**防災**です。

自治体の防災担当、鉄道・航空・電力といったインフラ企業、建設現場の安全管理、農業、物流。気象情報を読んで、事業判断や避難判断に落とし込める人が必要とされています。

2026年の熊本地震のような地震は予報できませんが、豪雨、台風、大雪、雷は予測の対象です。線状降水帯の発生、河川の増水、暴風。**いつ作業を止めるか、いつ避難を呼びかけるか**という判断は、気象情報を正確に読めなければできません。

気象業務法により、**予報業務を行う事業所には気象予報士の設置が義務づけられています**。民間気象事業者が予報を出すには、有資格者が必要です。

## 難関である。それは前提として

合格率は例年5%前後です。国家資格の中でも難度の高い部類に入ります。

試験は**学科（一般知識・専門知識）**と**実技**の3つ。

**学科・一般知識**は、大気の構造、熱力学、力学、降水過程、大気の放射、気候。物理の内容が正面から出ます。文系出身者が最初に壁を感じる部分です。

**学科・専門知識**は、観測、数値予報、短期・長期予報、局地予報、気象災害、予報の評価。実務的な内容です。

**実技**が本丸です。天気図を読み、前線を解析し、擾乱の構造を説明し、防災上の着目点を記述する。**記述と作図が中心**で、選択式ではありません。

## 免除制度を計画に組み込む

学科試験に合格すると、**その合格は1年間有効**です。次回以降、その科目が免除されます。

これを前提に計画を立てるのが定石です。

1回目で学科2科目を取る。2回目で実技に集中する。この組み方なら、1回あたりの負荷が現実的な範囲に収まります。

**逆に、無計画に3つ同時を狙い続けるのが最も非効率**です。学科の勉強に時間を取られて実技の練習量が確保できず、両方中途半端になります。

## 実技はなぜ難しいのか

実技試験の本質は、**天気図から現象を読み取る**ことです。

等圧線の間隔から風速を推定する。温度移流を読む。前線の位置を決める。渦度と上昇流の関係を見る。エマグラムから大気の安定度を判定する。

これらはすべて**図を読む技術**です。文章で「温暖前線の後面では暖気移流が卓越する」と読んでも、天気図の上でそれをどう確認するかが分からなければ、実技では一点も取れません。

そして解答も作図を含みます。前線を描く、等値線を引く、着目点を示す。

つまり**入力も出力も図**という、極めて特殊な試験です。

## QualiZの気象予報士

**要点テキスト300セクション・約61.8万字**を、学科一般150節／学科専門150節に配分しています。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。大気の熱力学のように物理の前提が要る分野も、導入から積み上げる構成にしています。

**問題は1,200問**。全問に、選択肢ごとの正誤解説をつけています。

**全1,200問に図解**があります。大気の鉛直構造は高度と温度のグラフで、前線は断面図で、渦度は流れの模式図で、エマグラムは図そのものを読む練習として。**図が入力になる試験なので、図に慣れておくことが実技対策の土台**になります。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。**学科免除を使って複数回の受験を計画する試験なので、年額プランとの相性が良い**資格です。

各科目10問まで無料です。
