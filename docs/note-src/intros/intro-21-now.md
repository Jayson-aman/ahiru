# 【総論】施工管理の人材が、いま制度的に足りていない

> note掲載用。タイトル案：
> - 「監理技術者がいない」だけで工事が止まる、という話
> - 施工管理の人手不足は、もう「将来の課題」ではなくなった
> - 資格が“あると良いもの”から“ないと回らないもの”に変わる年

---

建設業では2024年4月から、時間外労働の上限規制が適用されています。労働時間を減らしながら同じ工事量をこなすには、工程を組み立てられる人間が現場ごとに必要になります。

これは抽象的な話ではありません。**監理技術者・主任技術者が確保できなければ、その工事を受注できない**という具体的な制約です。

## 配置義務という、なくならない需要

施工管理技士は、建設業法上の「主任技術者」「監理技術者」になれる資格です。一定規模以上の工事には、これらの技術者を専任で配置する義務があります。会社が工事を受注できるかどうかが、有資格者が何人いるかに直接かかっているということです。

建設業就業者の高齢化はよく指摘されるとおりで、資格を持ったまま引退していく層と、これから資格を取る層の数が釣り合っていません。この差は、資格保有者の交渉力として表れます。

配置義務を持つのは施工管理技士だけではありません。危険物取扱者、消防設備士、給水装置工事主任技術者、宅地建物取引士、マンション管理業務主任者。いずれも「有資格者を置かなければ事業を続けられない」という構造を持っています。設備の老朽化や災害復旧のたびに、この構造の重みは増していきます。

## 「取るに越したことはない」の中身

資格を勧める文章はたいてい「取っておいて損はない」で終わります。それだと弱いので、もう少し具体的に書きます。

**第一に、配置義務のある資格は景気の影響を受けにくい**。工事量が減っても、工事をするなら技術者は要ります。保安の仕事は、設備が存在する限り発生します。需要が売上ではなく法令に紐づいているというのは、かなり強い性質です。

**第二に、資格手当は毎月出る**。多くの企業で施工管理技士や設備・保安系の資格には手当がつきます。仮に月1万円なら年12万円、10年で120万円。試験勉強にかけるコストとの比較で考えると、回収期間はそれほど長くありません。

**第三に、転職市場での通り方が変わる**。実務経験は面接で説明しないと伝わりませんが、資格は書類の段階で伝わります。書類で落とされなくなるというのは、思っているより大きな差です。

## それでも、勉強は続かない

ここまで書いておいて何ですが、資格取得の最大の障壁は「必要性が分からないこと」ではありません。**必要だと分かっていても続かないこと**です。

参考書を買った。最初の30ページは読んだ。そこから開いていない。この経験がある人は多いと思います。

理由ははっきりしていて、参考書は「読む」ようにできていて「分かる」ようにできていないからです。施工管理のネットワーク工程表、湿り空気線図、構造力学の応力図。文章だけで理解するには無理がある内容を、文章だけで説明しようとしている。図が足りないんです。

## QualiZという選択肢

私たちが作ったQualiZ（クオリズ）は、この「図が足りない」を出発点にしたアプリです。

収録している21資格すべてで、**問題文と選択肢に加えて、なぜその選択肢が誤りなのかを一つずつ解説しています**。そして全29,150問に図解を添えています。仕組み・数値・流れを目で追えるようにしてあります。

要点テキストは1資格あたり300セクション以上、全体で5,945セクション・約1,229万字。市販の参考書を何冊分も超える分量ですが、各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」という同じ順番で並んでいるので、どこから読んでも迷いません。

学習データは端末内に保存され、アカウント登録は不要です。通勤中に3セクション読む、昼休みに10問解く、という使い方を想定しています。

各資格の詳しい紹介は、それぞれ個別の記事にまとめています。まずは無料で各科目10問まで解けるので、問題の質を見てから判断してください。
