# 10年後、この国の現場を誰が回すのか ——「配置義務」という視点から資格を考える

> note掲載用。タイトル案：
> - 10年後、この国の現場を誰が回すのか
> - 資格が「あると良いもの」から「ないと現場が止まるもの」に変わる
> - 人手不足は、めぐりめぐって物価に返ってくる

---

## 誰かが点検しなければならない

2026年8月5日、経済産業省が全国のLPガス販売事業者に対して、商業施設や病院など大型施設のガス設備を点検するよう要請しました。

きっかけは、7月28日に熊本県嘉島町のイオンモール熊本で起きた爆発事故です。7名の方が亡くなり、5名が負傷されました。経産省の公表によれば、令和8年熊本地震で建物内のLPガス配管が損傷し、漏れたガスが滞留して引火した可能性が高いとされています。

この記事は、その事故を材料に何かを売るために書くものではありません。ただ、この出来事から動かしがたい事実がひとつ導かれます。

**行政が「点検してください」と言ったとき、その点検を実施できるのは有資格者だけです。**

LPガス設備の調査・点検は、液化石油ガス法によって有資格者の業務と定められています。高圧ガスを扱う事業所には、高圧ガス保安法によって保安統括者や保安技術管理者の選任義務があります。これは努力目標ではなく、法律上の義務です。

人手が足りないからといって、無資格者に代わってもらうという逃げ道がありません。ここが、他の多くの仕事と決定的に違うところです。

そして今回の要請は、日常点検の枠を超えて「地震で損傷した配管を見つけ出す」という難度の高い仕事を含んでいます。目視で分からない損傷をどう疑い、どこを重点的に見るか。それは資格試験で問われる知識そのものです。

## 災害は続く。そのたびに現場が要る

地震は熊本だけの話ではありません。政府の地震調査委員会は2025年9月、南海トラフ地震が今後30年以内に発生する確率について、算出方法を12年ぶりに見直したうえで「**60〜90%程度以上**」と「**20〜50%**」という2つの数値を併記しました。従来の「80%程度」から表現が変わりましたが、調査委は「どちらも確率として高いという評価に変わりはない」としています。

低いほうの20〜50%を採っても、**5回に1回から2回に1回**の話です。それ以外にも、毎年のように豪雨災害や土砂災害が起きています。

災害が起きれば、必ず復旧工事が発生します。損傷した構造物を診断し、応急処置を施し、本格的な補修を計画する。そのすべてに技術者が必要です。

平時のインフラ更新も止まりません。高度成長期に整備された橋梁、トンネル、上下水道、水道管が、一斉に更新時期を迎えています。新設よりも維持・更新の比重が上がるというのは、仕事が減るのではなく難しくなるということです。稼働中の施設を止めずに直す工事は、新設より制約が多く、段取りを組める人でなければ回りません。

**仕事の総量は減らない。むしろ増える。** それなのに、担い手のほうが減っています。

## 10年後に何が起きるか

数字で見ると、状況ははっきりしています。国土交通省の資料によれば、2024年時点の建設業就業者のうち、

- **55歳以上が36.7%**（全産業は32.4%）
- **29歳以下は11.7%**（全産業は16.9%）

入ってくる若手が全産業平均より少なく、抜けていく高齢層が全産業平均より多い。この構成では、時間が経つほど人が減ります。

就業者数そのものも減り続けています。ピークだった1997年の**685万人**から、2010年に504万人、2023年には**483万人**。**四半世紀で約3割減**という規模です。

そして、いま建設業を支えている中核層は団塊ジュニア世代です。1971年から74年生まれのこの世代は、2026年時点で52歳から55歳。**10年後には62歳から65歳になります。** 55歳以上が36.7%という数字の中身の、かなりの部分がこの世代です。

この世代が現場から退いたあとを、誰が引き継ぐのか。ここが日本の建設業が抱えている最大の問題です。

数の上での人手不足は、外国人材の受け入れによってある程度埋められてきました。実際、鳶職の班を見ると、親方が日本人で、あとの4〜5名はベトナム、インドネシア、カンボジアの方という編成が珍しくありません。彼らが現場を支えている事実は、率直に認めるべきだと思います。

しかし、それとは別に解決していない問題があります。**資格を持ち、図面を読み、法令を理解し、工程を設計し、そして次の世代に教えられる人**が、退職と同時にいなくなりつつあるということです。

施工管理技士や電気主任技術者のような資格は、単なる技能の証明ではありません。建設業法や電気事業法が「この工事にはこの資格者を専任で配置せよ」と定めている、制度上の必須要件です。だから有資格者がいなければ、どれだけ働き手がいても、その工事は受注できません。

技能は、教えられる人がいなければ伝わりません。教える側になるには、まず自分が体系的に学び、資格という形で裏づけを持つ必要があります。国籍を問わず、**次にこの役割を担う人を今から育てておかないと間に合わない**、というのが10年という時間の意味です。

## 人手不足は、物価に返ってくる

もうひとつ、見落とされがちな話をします。

人が足りなくなると、まず人件費が上がります。人件費が上がると、工事費が上がります。工事費が上がると、建物の価格が上がり、賃料が上がり、インフラの維持コストが上がります。それは最終的に、私たちが払う値段に転嫁されます。

**人手不足は、めぐりめぐって物価上昇として全員に返ってくる**ということです。

これを止める方法は、担い手を増やすことしかありません。そして建設・設備・保安の分野では、「担い手を増やす」は「有資格者を増やす」とほぼ同義です。配置義務が法律で決まっている以上、有資格者の数がそのまま供給能力の上限になるからです。

資格取得は、個人にとってのキャリア形成であると同時に、この構造への直接的な処方箋でもあります。

## 資格を取ることの、身も蓋もない利点

大きな話をしましたが、個人にとっての利点も具体的に書いておきます。

**配置義務のある資格は、景気に左右されにくい。** 工事量が減っても、工事をする以上は技術者が要ります。保安の仕事は、設備が存在する限り発生します。需要が売上ではなく法令に紐づいているというのは、資格としてかなり強い性質です。

**資格手当は毎月出る。** 多くの企業で施工管理技士や設備・保安系の資格には手当がつきます。仮に月1万円なら年12万円、10年で120万円。試験勉強にかけるコストとの比較で考えれば、回収期間はそう長くありません。

**書類の段階で伝わる。** 実務経験は面接で説明しないと伝わりませんが、資格は履歴書に書いた時点で伝わります。書類選考で落ちなくなるというのは、思っているより大きな差です。

## それでも、勉強は続かない

ここまで書いておいて何ですが、資格取得の最大の障壁は「必要性が分からないこと」ではありません。**必要だと分かっていても続かないこと**です。

参考書を買った。最初の30ページは読んだ。そこから開いていない。心当たりのある方は多いと思います。

理由ははっきりしています。参考書は「読む」ようにはできていますが、「分かる」ようにはできていないからです。ネットワーク工程表のクリティカルパス、湿り空気線図の状態変化、構造力学の応力図、LPガスの燃焼計算、高圧ガスの断熱膨張。**文章だけで理解するには無理がある内容を、紙面の制約から文章だけで説明している。** 図が足りないんです。

### 全問に、選択肢ごとの解説と図解

収録している**25,190問すべて**に、正解の理由だけでなく「なぜ他の選択肢が誤りなのか」の解説をつけています。そして**全問に図解**があります。

工程表はクリティカルパスを色分けした図で。湿り空気線図は線図そのものの上で状態変化を追えるように。ガスの供給設備は、ボンベから燃焼器までの経路を1枚の図に。断熱膨張は、圧力・体積・温度の関係を目で追えるように。文章を10回読むより図を1回見たほうが早い場面は、確実にあります。

### 要点テキストは総計6,577セクション・約1,255万字

21資格それぞれで300セクション以上の要点テキストを収録しています。各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」という同じ順番で構成しているので、予備知識がなくても最初のページから読み進められます。

法改正・最新統計にも対応しています。建設業法の金額要件、区分所有法・標準管理規約の改正、税制改正など、古い数値を覚えてしまう心配がありません。
