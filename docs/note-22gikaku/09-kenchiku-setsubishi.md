# 建築設備士 —— 建築士に「意見を述べる」ことができる立場

> note掲載用。タイトル案：

> - 空調・電気・給排水を横断できる人は、なぜ少ないのか
> - 一級建築士への近道としての建築設備士

---

## この資格の位置づけ

建築設備士は、建築士法に規定された資格です。一定規模以上の建築物の設備設計・工事監理にあたって、**建築士は建築設備士の意見を聴くよう努める**と定められています。

「意見を述べる立場が法律に書かれている」というのは、設備技術者にとって大きな意味を持ちます。施工の担当者としてではなく、設計段階から関与できる根拠になるからです。

さらに実務上大きいのが、**建築設備士として4年以上の実務経験を積むと、一級建築士の受験資格が得られる**という点です。建築系の学歴がない設備技術者にとって、一級建築士へ至る現実的なルートになっています。

## 求められるのは「横断性」

この資格が難しいのは、範囲が空調・衛生・電気の全域にわたるからです。

空調が得意な人は電気が弱い。電気が得意な人は給排水を知らない。実務では専門が分かれるのが普通なので、全部を等しく問われる試験は構造的にきついわけです。

しかし裏を返せば、**横断できる人が少ないから価値がある**。建物の設備を全体として設計・調整できる人材は、そう多くありません。

試験は一次（学科）と二次（設計製図）に分かれます。

**一次**は、建築一般知識・建築法規・建築設備の3科目。建築設備の配点が大きく、ここが本体です。

**二次**は設計製図。空調・衛生・電気のいずれかを選択して、実際に設備設計を行います。時間内に図面を仕上げる訓練が必要で、独学ではもっとも対策が難しい部分です。

## 学科でつまずく論点

**湿り空気線図**。空調分野の最大の関門です。図の上で状態変化を追えないと、加湿・除湿・混合の計算が全部あやふやになります。

**空調負荷計算**。外皮からの熱、日射、内部発熱、外気負荷。積み上げの構造を理解する必要があります。

**照度計算と幹線設計**。光束法、電圧降下、幹線サイズの選定。電気が専門でない人がまとめて落とす分野です。

**給排水の管径と通気**。器具給水負荷単位、同時使用率、封水の保護。配管図で押さえないと暗記になります。

**防災設備**。消火設備、排煙設備、非常用照明。法規と設備仕様が絡むので、条文と図の両方が要ります。

**建築法規**。建築基準法、消防法、建築士法。設備技術者にとっては馴染みが薄く、後回しにされがちな分野です。

## QualiZの建築設備士

**要点テキスト300セクション・約76.5万字**——これは収録22資格の中で最大級の分量です。範囲の広さに正面から対応するため、一般50節／法規50節／空調50節／給排水衛生50節／電気50節／防災50節の6分野に均等配分しています。

得意分野と苦手分野で情報量に差が出ないようにしてあるので、「電気だけ薄い」といったことが起きません。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。専門外の分野をゼロから読み始められる構成にしています。

**問題は2,919問**と、収録資格の中でもトップクラスの分量です。全問に、選択肢ごとの正誤解説をつけています。

**全2,919問に図解**を添えています。湿り空気線図は線図そのもので、幹線は単線結線図で、通気は配管立面図で。専門外の分野を学ぶときほど、図の有無が効きます。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。二級建築士や管工事施工管理技士も収録しているので、建築系を横断するなら全22資格が使い放題の月額2,800円／年額28,000円が向いています。

各科目10問まで無料です。
