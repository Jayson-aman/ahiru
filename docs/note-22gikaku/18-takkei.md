# 宅地建物取引士 —— 5人に1人、という設置義務

> note掲載用。タイトル案：
> - 宅建は「従業者5人に1人」が法律で決まっている
> - 権利関係で沈む人と、法令上の制限で沈む人
> - 20万人が受けて、8割が落ちる試験の攻略順序

---

## 需要が人数で決まっている

宅地建物取引士、通称「宅建」。

宅建業法は、宅建業を営む事務所に対して、**業務に従事する者5人につき1人以上**の専任の宅地建物取引士を置くことを義務づけています。

この「5人に1人」という比率が、需要をそのまま決めています。不動産会社が人を増やせば、有資格者も増やさなければならない。欠員が生じれば、法定の割合を満たすまで補充する義務があります。

さらに、重要事項の説明、重要事項説明書への記名、契約書面への記名は**宅建士でなければできません**。不動産取引そのものが、この資格者を経由しなければ成立しない構造です。

不動産業界だけでなく、金融機関の融資担当、建設会社の営業、企業の総務・不動産管理でも評価されます。年間20万人前後が受験する、国内最大級の国家資格です。

## 合格率17%前後の意味

宅建の合格率は例年15〜18%程度です。相対評価で、合格点は年によって変動します。

「簡単ではないが、正しくやれば届く」というのが実感に近いところです。ただ、独学で落ちる人には共通した失敗パターンがあります。

**権利関係から始めて、そこで力尽きる。**

出題は50問。内訳はおおよそ、宅建業法20問、権利関係14問、法令上の制限8問、税・その他8問です。

権利関係は民法が中心で、抽象的で難しい。しかも14問しかない。一方、宅建業法は20問と最大で、しかも**得点しやすい**。

にもかかわらず、多くの参考書は権利関係から始まります。順番どおりに読むと、いちばん難しくて配点の低い分野に最初のエネルギーを使い果たすことになります。

**宅建業法から入るべきです。** ここで安定して16〜18点を取れるようにしてから、権利関係に向かう。この順序を変えるだけで結果が変わる人はかなりいます。

## 分野ごとのつまずき

**権利関係**。意思表示、代理、時効、抵当権、賃貸借、相続。**当事者が3人以上出てくると混乱する**のが典型です。AがBに売り、BがCに転売した——という関係を、頭の中だけで追うのは無理があります。

**宅建業法**。免許、営業保証金、媒介契約、重要事項説明、37条書面、報酬額の制限、8種制限。細かい数値と期限が大量に出ます。

**法令上の制限**。都市計画法、建築基準法、国土利用計画法、農地法、宅地造成規制。**用途地域と建蔽率・容積率、斜線制限**は空間的な規定なので、文章だけでは把握できません。

**税・その他**。不動産取得税、固定資産税、印紙税、譲渡所得、地価公示、住宅金融支援機構。**毎年改正が入る分野**なので、古い教材は致命的です。

## QualiZの宅地建物取引士

**要点テキスト300セクション・約66.2万字**を、権利関係75節／宅建業法75節／法令上の制限75節／税・その他75節に均等配分しています。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順で構成されています。

**問題は3,590問**——収録資格の中でも最大級の分量です。全問に、選択肢ごとの正誤解説をつけています。宅建は「4つの選択肢のうち誤っているものを選べ」という形式が多いので、**誤答理由の理解が直接得点に結びつきます**。

**全3,590問に図解**を添えています。権利関係は当事者の関係図で、法令上の制限は敷地と建物の断面図・平面図で、業法の期限は時系列の図で。**登場人物が3人以上出る民法の問題こそ、関係図が効きます**。

さらに、**本試験形式の模試を5年度分**収録しています。令和元年度から令和5年度までの形式で、それぞれ50問・タイマー付き。年度ごとの合格点も設定してあるので、本番の感覚を掴めます。

税制改正、地価公示、統計数値は最新のものに対応しています。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。マンション管理士やFPも収録しているので、不動産・金融系をまとめて狙うなら全22資格が使い放題の月額2,800円／年額28,000円が有利です。

各科目10問まで無料です。
