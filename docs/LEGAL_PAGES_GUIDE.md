## 2. 直す前に「全部洗う」

一番やりがちな失敗が **直し漏れ**。1か所直して安心してしまう。
販売経路が増えたときは、**古い経路の名前を全文検索**して、
出てきた場所を全部見る。

```bash
cd /path/to/ahiru
python3 - <<'PY'
import re, pathlib
for name in ('tokushoho.html','terms.html','support.html','privacy.html'):
    t = re.sub(r'<[^>]*>', '', pathlib.Path('docs/legal', name).read_text())
    print('#'*8, name)
    for line in t.split('\n'):
        if re.search(r'Apple|Google|各ストア', line):   # ← 探したい語
            print('  -', line.strip()[:200])
PY
```

HTMLタグを外してから検索するのがコツ。タグ込みで grep すると
タグの途中で切れて見落とす。

**今回これで5か所→13か所に増えた。** 最初の見積りの2倍以上あった。

## 3. 「書き換え」ではなく「併記」にする

Apple / Google の記述を消してはいけない。**アプリで買った人には正しい**ので、
消すとそちらが嘘になる。

```
× Apple ID から解約してください
   → クレジットカードで請求されます        （アプリ購入者に嘘）

○ ・アプリ内でご購入の場合：Apple ID から
   ・ウェブサイトでご購入の場合：管理用リンクから  （どちらも正しい）
```

## 5. 文言の整合だけで済まない2点

ここは**事業判断**が入る。文言を合わせるだけでは終わらない。

### 返金の窓口

アプリ購入はストアが返金を代行してくれる。**Webにはその窓口が無い。**
「各ストアの規定により認められる場合を除き返金しません」だけだと、
Web購入者に一切返金できない建付けになってしまう。
→ **「または当社が個別に認めた場合」** を除外事由に追加した。

### サービス終了時の扱い（第9条）

旧：「各ストアの規定に従って取り扱われます」＝ Web購読者は**無定義**。
2案を検討し、**未経過期間分を返金する**案を採用した。
月額1,800円なので返金額は小さく、定めが無い状態を避けることを優先した。

## 6. アプリ側にも同じ文言がある

`components/CertPaywall.tsx` の `SUBSCRIPTION_NOTE`。
**ストア審査の必須項目**なので消さないこと。
`Platform.OS === 'web'` で出し分けている。

法定ページだけ直してここを忘れると、**購入画面には古い説明が出たまま**になる。
法定ページを直したら必ずここも見る。

## 7. 改定日を忘れずに

`terms.html` の末尾に「最終改定日」がある。**実質的な変更をしたら更新する。**
中身を変えたのに日付が古いままだと、それ自体が不備になる。
privacy.html にも同じ行があるが、**変更していないページの日付は触らない。**

## 8. 反映の確認

```bash
git add docs/legal components
git commit -m "..."
git push -u origin <branch>
```

GitHub Pages は push の1〜2分後に反映される。
公開URLを開いて、**ブラウザのキャッシュを無視して再読込**（macOS Safari は
⌘+Option+R）してから確認する。

## 9. 未確定事項

Web購入者の解約リンクが実際にどう届くかは**未確認**。
RevenueCat の SDK には `customerInfo.managementURL` があるが
（`node_modules/@revenuecat/purchases-js/dist/Purchases.es.d.ts:107`）、
RevenueCat Billing がこの値を埋めるかは未確認。アプリは現在これを使っていない。

そのため文言は **「購入完了メールに記載の管理用リンクから、または
info@zaibase.group へのご連絡により」** と両対応で書いてある。
どちらの実装になっても嘘にならない。

本番のテスト購入ができるようになったら、**実際に届くメールを確認**して、
管理用リンクが本当にあるかを確かめる。無ければメール解約のみに文言を寄せる。
