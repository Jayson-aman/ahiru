## 「新しい」ことがそのまま強みになる

1級電気通信工事施工管理技士は、2019年度に新設された比較的新しい国家資格です。

新設資格には特有の有利さがあります。**まだ有資格者の絶対数が少ない**ということです。歴史の長い資格なら、業界にすでに十分な数の保有者がいます。しかしこの資格は、制度が始まってからの年数が短いぶん、供給が追いついていません。

一方で需要側は動いています。5G基地局の整備、光ファイバ網の更新、データセンターの構内配線、監視カメラシステム、施設内の無線LAN整備。通信インフラの工事は増加傾向にあり、それを仕切る施工管理者が要ります。

この資格は建設業法上の**監理技術者**および**専任技術者**の要件を満たします。電気通信工事業の許可を持つ会社にとって、受注可能な工事の規模を決める人材です。

## 試験の中身

**電気通信工学**。伝送理論、変調方式、デジタル信号処理、アンテナ、光通信。通信という目に見えない現象を扱うので、抽象度が高い分野です。

**電気通信設備**。有線・無線・ネットワーク・放送・情報設備。守備範囲が広く、それぞれの設備構成を押さえる必要があります。

**施工管理法**。工程・品質・安全・原価。他の施工管理技士と共通する枠組みです。

**法規**。建設業法、電気通信事業法、電波法、労働安全衛生法。電波法が入るのがこの資格の特徴です。

つまずくのは、やはり**目に見えないものを扱う**部分です。変調方式の違い、光ファイバの伝送損失、ネットワークの階層構造。これらは文章で読んでも像を結びません。伝送路の構成図、変調波形、プロトコルの階層図。図があってはじめて意味が取れる分野です。

また、新設資格ゆえに市販の教材が他資格ほど充実していないという実務上の問題もあります。選択肢が少ないのは、学習者にとっては不利な条件です。

## QualiZの1級電気通信工事施工管理技士

**要点テキスト300セクション・約63.4万字**を、電気通信工学75節／電気通信設備75節／施工管理75節／法規75節に均等配分しています。教材が少ない分野で、まとまった分量を体系立てて用意することを重視しました。

各セクションは「ゼロからの導入 → 要点整理 → 図解 → 頻出ひっかけ → ここだけ暗記」の順。通信工学のような抽象度の高い分野こそ、導入から積み上げる構成が効きます。

**問題は600問**。全問に、選択肢ごとの正誤解説をつけています。

**全600問に図解**を添えています。変調方式は波形で、光ファイバは断面と伝搬経路で、ネットワークは階層図で示します。

本試験形式の模試はタイマー付きです。

料金は月額1,800円／年額18,000円（年額は2か月分お得）。電気工事施工管理技士など他分野と併せるなら、全21資格が使い放題の月額2,800円／年額28,000円が有利です。

各科目10問まで無料です。
